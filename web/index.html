Quantum Dice Tool

Install new firmware, back up or change your dice's settings, and see what your dice is doing.

This browser cannot connect to the Quantum Dice

This page talks to the dice over USB, which only works in Google Chrome or Microsoft Edge on a computer (Windows, macOS, Linux or ChromeOS). Safari, Firefox and phones or tablets are not supported.

Please open this page again in Chrome or Edge.

1

Connect your dice

  1. Switch the dice on and make sure it is awake (the screens are on).
  2. Connect it to this computer with a USB-C cable. Some cables can only charge; if nothing shows up, try another cable.
  3. Click Connect and choose the dice in the list that appears (it is usually called USB JTAG/serial debug unit).

Settings file

The dice keeps its settings (its name, colours and a few advanced values) in a small text file called <name>_config.txt. Here you can save it to your computer, or put a changed file back on the dice.

Save settings to this computer

Reads the settings file from the dice (takes up to a minute).

Put a settings file on the dice

Choose a …_config.txt file. It is checked before anything is written.
